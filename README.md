# Mom's Basement

An interactive, walkable basement experience inspired by immersive clubhouse-style sites (but original).

## Features
- First-person style movement (touch drag to look, on-screen buttons or WASD to move)
- Stairs that lead to an upper landing
- Toilet door and main room furniture
- Clickable objects with descriptions
- Works on mobile and desktop
- Atmospheric lighting

## How to run
1. Open `index.html` in a modern browser (or serve the folder locally).
2. On mobile: drag to look, use the buttons to move.
3. On desktop: drag with mouse or use WASD + mouse drag.
4. Tap/click objects (couch, TV, doors) to inspect them.
